# KINO Monitor for Windows

Προσωπικό Windows monitor για τις κληρώσεις ΚΙΝΟ του ΟΠΑΠ.

## Τι κάνει

- Ελέγχει το επίσημο OPAP API **ένα λεπτό μετά από κάθε 5λεπτη κλήρωση**, δηλαδή `00:01, 00:06, 00:11, ... 23:56`.
- Αν το νέο αποτέλεσμα δεν έχει ακόμη δημοσιευτεί, κάνει έως 4 επιπλέον retries ανά 15 δευτερόλεπτα.
- Αποθηκεύει τοπικά κάθε νέα κλήρωση σε SQLite.
- Μετρά τους 20 αριθμούς και χαρακτηρίζει:
  - **ΜΟΝΑ**: >10 μονοί αριθμοί
  - **ΖΥΓΑ**: >10 ζυγοί αριθμοί
  - **ΙΣΟΠΑΛΙΑ**: 10 μονοί / 10 ζυγοί
- Παρακολουθεί:
  - συνεχόμενες κληρώσεις **χωρίς αποτέλεσμα ΜΟΝΑ**,
  - συνεχόμενες κληρώσεις **χωρίς αποτέλεσμα ΖΥΓΑ**,
  - συνεχόμενες **ΙΣΟΠΑΛΙΕΣ**.
- Στέλνει Windows notification όταν κάποιος από τους δύο πρώτους μετρητές γίνει **3 ή περισσότερο**.
- Η ειδοποίηση στέλνεται μία φορά όταν ξεπεραστεί το όριο και ξαναοπλίζει όταν εμφανιστεί ξανά το αντίστοιχο αποτέλεσμα.
- Στην εκκίνηση φορτώνει έως 50 πρόσφατες κληρώσεις της ημέρας και, αν διαπιστώσει κενό στα draw IDs, κάνει backfill ώστε να μην χάνονται αποτελέσματα μετά από sleep ή προσωρινή διακοπή Internet.

## Πηγή δεδομένων

Το πρόγραμμα χρησιμοποιεί το OPAP draws API για το KINO (`gameId=1100`) και όχι HTML scraping.

Κύριο endpoint:

`https://api.opap.gr/draws/v3.0/1100/last-result-and-active?status=results`

Fallback:

`https://api.opap.gr/draws/v3.0/1100/draw-date/YYYY-MM-DD/YYYY-MM-DD?size=300`

## Εκτέλεση από Python

Απαιτεί Python 3.11+ στα Windows.

1. Κατέβασε τον φάκελο `kino-monitor`.
2. Διπλό κλικ `run.bat`.
3. Στην πρώτη εκτέλεση θα εγκατασταθούν τα απαραίτητα packages.

## Δημιουργία .exe

1. Διπλό κλικ `build.bat`.
2. Το τελικό αρχείο θα δημιουργηθεί ως `dist\KinoMonitor.exe`.

## Αυτόματη εκκίνηση με Windows

Μετά το build, άνοιξε PowerShell μέσα στον φάκελο και τρέξε:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_startup.ps1
```

## Τοπική βάση

Η βάση αποθηκεύεται στο:

`%LOCALAPPDATA%\KinoMonitor\kino_monitor.sqlite3`

Αποθηκεύονται: draw id, ημερομηνία/ώρα, 20 αριθμοί, πλήθος μονών, πλήθος ζυγών και τελικό αποτέλεσμα.

## Λογική ειδοποίησης

Παράδειγμα αποτελεσμάτων: `ΖΥΓΑ → ΙΣΟΠΑΛΙΑ → ΖΥΓΑ` σημαίνει 3 συνεχόμενες κληρώσεις χωρίς **ΜΟΝΑ**, άρα στέλνεται ειδοποίηση.

Αν εμφανιστεί μετά `ΜΟΝΑ`, ο μετρητής «Χωρίς ΜΟΝΑ» μηδενίζεται και η ειδοποίηση ξαναοπλίζει.

## Σημείωση

Το εργαλείο καταγράφει και ειδοποιεί βάσει δημοσιευμένων αποτελεσμάτων. Δεν προβλέπει μελλοντικές κληρώσεις και ένα streak δεν αλλάζει την πιθανότητα μιας επόμενης ανεξάρτητης κλήρωσης.
