# KINO Monitor for Windows

Προσωπικό Windows monitor για τις κληρώσεις ΚΙΝΟ του ΟΠΑΠ, με αυτόματα email alerts σε **δύο παραλήπτες**.

## Τι κάνει

- Ελέγχει το OPAP API ένα λεπτό μετά από κάθε 5λεπτη κλήρωση: `00:01, 00:06, 00:11, ... 23:56`.
- Αν το αποτέλεσμα δεν έχει ακόμη δημοσιευτεί, κάνει retries.
- Αποθηκεύει κάθε κλήρωση σε SQLite.
- Χαρακτηρίζει κάθε κλήρωση ως:
  - **ΜΟΝΑ**: >10 μονοί
  - **ΖΥΓΑ**: >10 ζυγοί
  - **ΙΣΟΠΑΛΙΑ**: 10/10
- Μετρά συνεχόμενες κληρώσεις χωρίς ΜΟΝΑ και χωρίς ΖΥΓΑ.
- Όταν ένας μετρητής γίνει **3 ή περισσότερο**, στέλνει email alert.
- Το alert αποστέλλεται **ξεχωριστά σε δύο παραλήπτες**, ώστε ο ένας να μη βλέπει τη διεύθυνση του άλλου.
- Στέλνει μία ειδοποίηση ανά streak και ξαναοπλίζει όταν εμφανιστεί ξανά το αντίστοιχο αποτέλεσμα.
- Κάνει backfill μετά από sleep/προσωρινή διακοπή Internet.

## Ρυθμίσεις email

Μέσα στο πρόγραμμα πάτησε **Ρυθμίσεις email** και συμπλήρωσε:

1. Gmail αποστολέα
2. Παραλήπτη 1
3. Παραλήπτη 2
4. Gmail App Password

Το App Password δεν αποθηκεύεται στο GitHub. Προστατεύεται τοπικά με **Windows DPAPI** και μπορεί να αποκρυπτογραφηθεί μόνο από τον ίδιο Windows χρήστη.

Για Gmail χρησιμοποιείται `smtp.gmail.com`, port `465`, SSL.

> Χρησιμοποίησε App Password Google, όχι τον κανονικό κωδικό Gmail. Για App Password απαιτείται 2-Step Verification στον Google λογαριασμό.

Μετά την αποθήκευση, πάτησε **Δοκιμή email**. Θα σταλεί ξεχωριστό δοκιμαστικό μήνυμα και στους δύο παραλήπτες.

## Αρχεία δεδομένων

- SQLite: `%LOCALAPPDATA%\KinoMonitor\kino_monitor.sqlite3`
- Ρυθμίσεις: `%LOCALAPPDATA%\KinoMonitor\config.json`

Στο `config.json` δεν υπάρχει ο κανονικός κωδικός Gmail ούτε plaintext App Password.

## Πηγή δεδομένων

Το πρόγραμμα χρησιμοποιεί το OPAP draws API για KINO (`gameId=1100`), όχι HTML scraping.

- `https://api.opap.gr/draws/v3.0/1100/last-result-and-active?status=results`
- `https://api.opap.gr/draws/v3.0/1100/draw-date/YYYY-MM-DD/YYYY-MM-DD?size=300`

## Σημείωση

Το πρόγραμμα καταγράφει δημοσιευμένα αποτελέσματα και ειδοποιεί βάσει streaks. Δεν προβλέπει μελλοντική κλήρωση και οι προηγούμενες κληρώσεις δεν αλλάζουν την πιθανότητα της επόμενης ανεξάρτητης κλήρωσης.
